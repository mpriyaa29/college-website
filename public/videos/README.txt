SKCET Campus Video Placeholder
================================

Place the actual SKCET campus video file here:
  public/videos/skcet-campus.mp4

Requirements:
- Format: MP4 (H.264) — also optionally add skcet-campus.webm for better browser support
- Resolution: 1920×1080 minimum (1920×1080 or 3840×2160 preferred)
- Duration: 30–90 seconds recommended (loops automatically)
- The video should show: campus buildings, students, labs, innovation spaces, campus life
- Ensure the video is optimized for web (compressed, ~10–50 MB ideal)

To replace:
1. Copy your video file to this folder as: skcet-campus.mp4
2. The VideoBackground component will automatically load it
3. No code changes required — only the asset file needs updating

Fallback:
- If no video is present or fails to load, the hero will display a dark gradient
- You can also add a fallback image: public/images/hero-fallback.jpg
